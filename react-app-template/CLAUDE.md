# React App — Claude Code Instructions

## Stack
- React 19, TypeScript 5 (strict), Vite 7
- Vitest 4 + Testing Library for tests
- ESLint 9 (flat config, `eslint.config.ts`) + Prettier
- pnpm 10 — use `pnpm`, never `npm` or `yarn`

## Commands
```bash
pnpm dev            # start dev server
pnpm build          # type-check + production build
pnpm test           # run tests once
pnpm test:coverage  # tests with coverage
pnpm lint           # ESLint
pnpm format         # Prettier write
pnpm typecheck      # tsc --noEmit
```

## Code Rules
- All new files must be `.ts` or `.tsx` — never `.js`
- Use `import type` for type-only imports (`@typescript-eslint/consistent-type-imports`)
- No `any` types — use `unknown` and narrow properly
- All React components: named exports, not default where avoidable
- Hooks must live in `src/hooks/`, shared types in `src/types/`
- Absolute imports via `@/` alias (`@/components/Button`)
- No `console.log` — use `console.warn` / `console.error` only
- Every new component needs a co-located test file `*.test.tsx`

## Test Rules
- Test files live in `tests/` or co-located as `*.test.tsx`
- Use `@testing-library/react` and `@testing-library/user-event`
- Never test implementation details — test behavior
- Coverage threshold: 80% all metrics

## Commit Rules

Format: `<type>(<scope>): <subject>` — subject max 72 chars, lowercase, no period.

```
feat(auth): add OAuth2 login flow
fix(ui): correct button contrast ratio
docs(readme): update setup instructions
```

**Allowed types:** `feat | fix | docs | style | refactor | perf | test | build | ci | chore | revert`

**Body** (optional): wrap at 100 chars, explain *why* not *what*.

**Footer** (optional): `BREAKING CHANGE: <description>` or `Closes #123`.

### Enforced by commitlint + husky
- Subject must be ≥ 3 chars and ≤ 72 chars
- Type must be from the allowed list above
- Scope must be lowercase alphanumeric + hyphens only

### Forbidden in commit messages
- `Co-Authored-By: Claude` / `Co-Authored-By: Copilot` / any AI agent name
- `Generated by Claude` / `Generated with AI` / `via Claude Code`
- `🤖` emoji or any AI attribution stamp
- `noreply@anthropic.com` or similar AI service emails

These are stripped by the husky `commit-msg` hook and rejected by the `no-agent-detail` commitlint rule.

## Do Not
- Do not install packages without asking
- Do not modify `.github/workflows/` without explicit instruction
- Do not commit `.env` files
- Do not use `// @ts-ignore` or `// eslint-disable` without justification

## Additional Best Practices

### Next.js / App Router
- **Server Components** — default, use 'use client' only when needed
- **Data fetching** — fetch in Server Components, use Suspense
- **Layouts** — use for shared UI, not for fetching
- **Route groups** — `(auth)`, `(dashboard)` for organization

### State Management
- **Server state** — use TanStack Query / SWR
- **Local state** — useState, useReducer for component-specific
- **Global state** — Zustand or Context for app-wide (theme, auth)
- **URL state** — React Router for shareable state
- **Don't overuse** — don't reach for global state too early

### Forms
- **React Hook Form** — for form state management
- **Zod** — for schema validation
- **Validate both** — client and server side

### Performance
- **Bundle splitting** — code-split routes with dynamic imports
- **Lazy loading** — `next/dynamic` for heavy components
- **Image optimization** — use `next/image`
- **Memoization** — useMemo, useCallback — don't overuse
- **Virtualization** — for long lists (react-window)

### Component Guidelines
- **Small components** — max 400 lines per file
- **Single responsibility** — each component does one thing
- **Composition over inheritance**
- **Prop drilling** — use context or composition

### Error Handling
- **Error boundaries** — wrap components to catch render errors
- **try/catch** — for async operations
- **User-friendly** — show meaningful messages to users

### Security
- **Validate inputs** — Zod schemas
- **Sanitize** — prevent XSS
- **No secrets** — never expose API keys in client code
