# Python Package — Claude Code Instructions

## Stack
- Python 3.12+ — `from __future__ import annotations` in every file
- uv for dependency management
- Hatchling build backend
- Ruff 0.15 for lint + format
- MyPy 1.14 strict
- Pytest + pytest-xdist for parallel testing

## Commands
```bash
uv sync --all-extras         # install all deps including dev
uv run pytest                 # run tests
uv run pytest --cov=mypkg -n auto  # parallel coverage
uv run ruff check src tests   # lint
uv run ruff format src tests  # format
uv run mypy src               # type check
uv build                      # build wheel + sdist
```

## Project Layout
- `src/mypkg/` — package source (src layout)
- `src/mypkg/__init__.py` — `__version__` lives here only
- `src/mypkg/py.typed` — PEP 561 marker, must stay
- `tests/` — test files, mirrors `src/mypkg/` structure

## Code Rules
- **src layout**: never import `mypkg` without `pip install -e .`
- Explicit `__all__` in every public module
- All public functions/classes must have Google-style docstrings
- `from __future__ import annotations` at top of every file
- `TYPE_CHECKING` guard for type-only imports
- No `print()` statements — use `logging`
- `py.typed` must never be deleted

## Test Rules
- Coverage threshold: 90% all metrics
- Test file mirrors source: `src/mypkg/utils.py` → `tests/test_utils.py`
- Use `pytest.mark.unit` for fast tests, `pytest.mark.integration` for slow ones

## Commit Rules

Format: `<type>(<scope>): <subject>` — subject max 72 chars, lowercase, no period.

```
feat(core): add streaming response support
fix(parser): handle empty input without raising
docs(api): add usage examples to README
```

**Allowed types:** `feat | fix | docs | style | refactor | perf | test | build | ci | chore | revert`

**Body** (optional): wrap at 100 chars, explain *why* not *what*.

**Footer** (optional): `BREAKING CHANGE: <description>` or `Closes #123`.

### Enforced by commitizen + pre-commit
- Schema pattern: `^(feat|fix|docs|style|refactor|perf|test|build|ci|chore|revert)(\([a-z0-9-]+\))?: .{3,72}$`
- `no-commit-to-branch` blocks direct commits to `main`

### Forbidden in commit messages
- `Co-Authored-By: Claude` / `Co-Authored-By: Copilot` / any AI agent name
- `Generated by Claude` / `Generated with AI` / `via Claude Code`
- `🤖` emoji or any AI attribution stamp
- `noreply@anthropic.com` or similar AI service emails

These are rejected by the `no-agent-detail` pre-commit pygrep hook (commit-msg stage).

## Release
1. Bump `__version__` in `src/mypkg/__init__.py`
2. Update `CHANGELOG.md`
3. `git commit -m "chore: release vX.Y.Z"`
4. `git tag vX.Y.Z && git push origin vX.Y.Z`
→ CI publishes to PyPI automatically via OIDC
